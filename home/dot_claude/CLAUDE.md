# Claude Code

- このファイルでは、共通ルールを繰り返さず、Claude Code または使用モデルに固有の差分だけを定義する。
- タスクの範囲を維持し、依頼されていない追加作業へ自発的に拡大しない。
- 自身が通常行う再確認に加えて、同じ内容の再検証やダブルチェックを追加しない。
- Subagent は、大きく独立して並列化できる作業に明確な利点がある場合にのみ使用する。少数の tool call で完了できる作業や、自分の結果を再確認するだけの目的では使用しない。
- 複数の Subagent を使う場合は、責務と成果物を分離し、同じ対象を重複して調査または変更させない。
- 作業中の説明は必要な場合だけ簡潔に行い、重要な発見、方針変更、阻害要因がある場合に更新する。
- 文書や説明の長さは内容に合わせ、不要な章、定型文、重複したまとめで膨らませない。
- 軽微な自己修正は黙って反映し、ユーザーのコード、結論、判断に影響する訂正だけを簡潔に明示する。
